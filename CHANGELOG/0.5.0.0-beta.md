# 方圆作业板（ImmersingHomework）0.5.0.0-beta

发布日期: 2026-11-15

## 📝 概述

这是 ImmersingHomework 在 0.4.0.1-beta 基础上的新版本。本版本的主题是「主界面重做」：主窗口从原来的一块静态作业面板，重做成带顶栏、瀑布流布局、可拖拽作业卡片、作业编辑抽屉与时光机的完整大屏界面，辅以背景图片、高级材质、主题色等一系列外观定制，以及作业增删改、快照切换的一套连贯动画。联动部分新增「指定提醒科目」与「连堂也提醒」两个作业布置提醒的细化设置，科目、标签、作业模板三个设置页也一并翻新为统一的列表卡片样式。

## ✨ 新功能

### 主界面

- 顶栏与工具按钮 - 主窗口新增顶栏，放上最小化 / 关闭、冻结、自动滚动、添加作业、时光机还原、分享、日期切换等按钮，主界面标题文字可自定义
- 瀑布流布局 - 作业面板由整齐网格改为瀑布流，科目按设置自动聚合，作业卡片高度随内容自适应，主界面列数可在设置中调整为 1~6
- 作业拖拽 - 作业卡片可拖动到任意科目分组与任意位置，松开后位置自动保存；拖拽过程中支持边缘自动滚动，作业的增删改会保持其余条目的相对位置不变
- 作业编辑抽屉 - 点按作业卡片从右侧滑出编辑抽屉，可直接增删改作业、选择标签、套用模板；新增「科目轮盘」，拖动即可快速切换科目
- 作业模板填充改进 - 模板参数输入框重新排布，参数未填写完整时退出抽屉会丢弃本次更改，避免写进半成品作业
- 长按解冻 - 冻结状态下改为长按解冻按钮才能解除冻结，避免误触；解冻动作与普通点击互不干扰
- 自动滚动 - 主界面可开启自动上下往复滚动，滚动速度可在设置中调整（10~300 像素/秒）
- 时光机 - 底部还原按钮唤出时光机：当天所有快照按时间横向排列，可左右滑动、点击或使用方向键切换，选中后可替换或与当前作业合并还原；快照较多时带横向拖动、两端回弹与加载进度环
- 背景与材质 - 主界面可设置背景图片，并调整透明度与模糊度；Windows 下支持开启高级材质（CompositionMaterial），仅顶栏、作业卡片与底部按钮栏透出材质，设置了背景图片时材质区域改为显示模糊后的图片
- 主界面标题文字 - 可在设置中自定义显示在主界面右上角的文字

### 动效

- 主界面动画 - 作业卡片入场、离线、位置交换与重组均带动画
- 作业修改动画 - 新增、修改、删除作业分别播放对应的过渡动画
- 时光机切换动画 - 在快照之间切换时，作业卡片以动画方式过渡到目标快照的内容

### 外观与设置

- 主题色 - 基础设置新增主题色选择器，按钮、开关与选中态均使用所选强调色；不设置时跟随系统强调色，「主题色」项同时加入了首次启动的欢迎向导
- 浮窗翻新 - 浮窗可吸附在屏幕左侧或右侧，只记忆纵向位置，外观重新设计；浮窗位置在基础设置与欢迎向导中均可选择
- 科目 / 标签 / 作业模板设置页翻新 - 三个设置页统一改为「列表卡片 + 顶部计数与添加按钮」的样式，支持拖动排序、编辑、删除，并补充空列表引导与 ClassIsland 接管科目的提示
- 标签深色配色 - 标签自动按底色生成可读性更好的文字与描边颜色，深色主题下不再发白

### ClassIsland 联动

- 指定提醒科目 - 「课后提醒布置作业」下新增「指定提醒科目」，可勾选只对哪些科目触发提醒，科目较多时自动换行
- 连堂也提醒 - 可设置上一节课与下一节课为同一科目（连堂）时是否仍然提醒
- 联动设置页改版 - 课后提醒相关的子项会跟随总开关启用 / 禁用，修复了子项挂在错误展开器上的问题

## 🔧 修复

- 修复作业输入组件无法回填已有作业所选模板的对应参数
- 修复「课后提醒布置作业」设置项初始化时绑定错误
- 修复「课后提醒布置作业」的判断逻辑错误（上一节为滚木时仍会提醒）
- 修复作业布置提醒窗口打开时尺寸过大
- 修复联动设置页科目选项不换行
- 修复主界面实时修改列数时崩溃
- 修复 Windows 下非全屏窗口无法拖动标题栏
- 修复高级材质区域仍透出桌面、导致无法点击文字以外的作业卡片打开编辑抽屉
- 修复冻结按钮切换一轮状态后高级材质失效
- 修复编辑作业后主界面卡顿
- 修复关于页文案未换行
- 修复主界面未正常退出

## ♻️ 重构与调整

- 主界面控件拆分 - 冻结按钮、作业编辑视图、科目轮盘、时光机、高级材质表面等均拆为独立控件，`MainWindow` 只负责编排
- 作业模型扩展 - 作业新增用于拖拽与相对排序的字段，科目聚合与排序逻辑下沉到 `Homework` 与作业面板
- 作业存储服务扩展 - `IHomeworkStorageService` 增加快照读取能力，供时光机按日期取当天全部快照
- 样式统一 - 新增 `SettingsListItem`、`SettingsListReorder`、`DialogHelper` 与全局 `settings*` 样式类，各设置页共用
- 一言设置暂时下线 - 主界面一言展示能力保留，但设置导航中的「一言设置」页暂时隐藏，待重新整理后再放出
- 空状态与包管理 - 更新 Avalonia 至 12.1.4、AvaloniaUI.DiagnosticsSupport 至 2.2.3，引入 CompositionMaterial.Avalonia 1.1.2
