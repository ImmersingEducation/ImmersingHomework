# 方圆作业板（ImmersingHomework）0.5.0.2-beta

发布日期: 2026-11-22

## 📝 概述

这是 ImmersingHomework 在 0.5.0.1-beta 基础上的新版本。本版本围绕主界面的日期体验做了小幅改进：查看其它日期时可一键「回到今天」，查看当天时顶部大标题会标注「今天」，并且切换日期或跨过零点后都能自动刷新提示；同时修正了顶栏多出一个退出按钮和高级材质不跟随卡片动画移动的问题。

## ✨ 新功能

- 回到今天 - 顶栏日期按钮左侧新增「回到今天」按钮，仅在当前查看日期不是今天时显示，点击即可切回当天作业；日期切换与窗口重新激活（例如跨过零点后）时按钮显示状态都会自动更新
- 今天提示 - 顶部大标题在查看当天日期时追加「今天」字样，查看其它日期时保持原样；窗口重新激活时也会重新判断，跨零点后无需手动刷新

## 🔧 修复

- 修复主界面顶栏多出一个退出按钮 - 移除界面上的关闭按钮，主界面为沉浸式全屏窗口，「最小化」即隐藏主界面并保留浮窗；真正退出仍走托盘菜单或异常窗口
- 修复高级材质未随动画移动 - 材质表面现在监听自身及祖先控件的 `RenderTransform` 变化，作业卡片动画直接修改 `TranslateTransform` 不再导致背景镂空区域错位；隐藏材质表面时也会刷新镂空，避免留下空洞
