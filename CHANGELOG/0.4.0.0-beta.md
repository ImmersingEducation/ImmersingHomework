# 方圆作业板（ImmersingHomework）0.4.0.0-beta

发布日期: 2026-10-05

## 📝 概述

这是 ImmersingHomework 在 0.3.0.0-beta 基础上的新版本。本版本的主题是「让大屏一直活着」与「让更新真正可用」：新增教学安全模式，应用异常时可自动重启 / 退出 / 提醒，并内置崩溃循环保护杜绝重启风暴；更新页面整体翻新为「状态总览 + 更新日志 + 更新选项」三段式，支持检查、下载、仅下载、打开更新目录、重启并应用更新与取消下载，Launcher 与主程序之间的更新交接链路打通。同时补齐了桌面快捷方式创建、自绘设置窗口标题栏、主窗口操作信息提示（InfoBar 浮层）等交互细节，并对浮窗移动逻辑做了重写。代码层面完成依赖注入（DI）改造，把 App 中手工 new 出来的服务收敛为统一的容器与导航工厂。

## ✨ 新功能

### 教学安全模式（新）
- 异常处理策略可选 - 基础设置页新增「教学安全模式」，提供**自动关闭** / **自动重启** / **显示提醒**三种策略，课堂场景下应用崩溃不再需要人工干预
- 异常时自动恢复 - 异常处理器不再无条件弹窗，按所选策略执行退出或重启；读取配置失败或配置非法时降级为「显示提醒」，保证不会因为设置损坏而再次崩溃
- 崩溃循环保护 - 新增跨进程崩溃计数（`Data/CrashState.json`，10 分钟窗口内 3 次即视为重启循环），此时不再自动重启而是弹出异常窗口把现场留给用户，避免无限闪退
- 异常处理去重 - 处理动作期间到达的新异常只记录日志，不重复退出或堆叠弹窗；异常窗口关闭后可继续处理下一次异常

### 自动更新
- 更新页面翻新 - 参考 ClassIsland 重做更新页：顶部状态总览（状态图标在检查 / 下载时旋转，附状态文案与说明）、错误信息条（检查失败 / 下载失败 / 强制更新 / 重启后应用）、按状态切换的操作按钮
- 完整更新链路 - 支持检查更新、下载并重启、仅下载、打开更新目录、取消下载、重启并应用更新、重新检查更新
- 更新日志页 - 发现新版本后可直接在设置内查看该版本的更新内容
- 更新选项页 - 支持选择更新渠道与更新行为（立即安装 / 立即下载 / 立即通知 / 不执行任何操作），并展示当前版本、运行平台、上次检查时间与更新包目录
- 更新页入口可见 - 设置窗口的导航中正式放出「更新」页签
- Launcher 交接更新 - 主程序与 Launcher 之间通过环境变量传递发布目录，统一更新包暂存目录、`update.flag` 标记与 `Temp/Update_vX.Y.Z.W` 的路径解析，未经过 Launcher 启动时回退到当前工作目录

### 桌面与窗口
- 创建快捷方式 - 设置窗口「更多」菜单新增创建桌面快捷方式与开始菜单快捷方式，支持 Windows（.lnk）与 macOS（.app 替身）实现，Linux / Wayland / X11 下自动跳过
- 自绘标题栏 - 设置窗口改为 `ExtendsContentIntoTitleBar` 自绘标题栏：macOS 走原生全屏装饰，Windows 用 `ExtendClientAreaTitleBarHeightHint` 覆盖 FluentAvalonia 写死的 32px 标题栏高度，统一到 48px
- 操作信息提示 - 主窗口右下角新增 InfoBar 消息浮层，成功 / 失败类操作不再只写日志，改为浮层渐显反馈，且不占用主布局行空间
- 浮窗移动逻辑重写 - 参考 SecRandom 重构浮窗的定位与拖动逻辑，跨屏移动、拖拽边界与位置记忆行为更稳

## 🔧 修复

- 修复「教学安全模式 → 自动重启」引发的重启风暴
- 修复未提供下载地址时被误报为「有可用更新」
- 修复自绘标题栏控件与系统窗口控制按钮重叠
- 修复标题栏窗口控制按钮高度与标题栏定义不一致
- 修复标题栏窗口控制按钮图标丢失
- 修复设置窗口「更多」按钮点击失效
- 修复 `FANavigationView` 汉堡菜单按钮字形丢失
- 修复 Windows 下 Launcher 启动时弹出控制台窗口

## ♻️ 重构与依赖

- 引入依赖注入 - 新增 `Abstractions/` 抽象层与 `ServiceCollectionExtensions` 注册入口，备份、作业存储、快照、输出、日志、平台、URL 协议、更新、ClassIsland 联动等服务统一由容器提供；新增 `DiNavigationPageFactory` 承担设置页导航创建
- 平台服务工厂 - 各平台实现（Windows / macOS / X11 / Wayland）抽出公共基类，URL 协议注册、快捷方式创建等能力按平台分发
- AppSettings 自实现持久化 - `AppSettings` 自行完成加载与保存并去除对 `Services` 层的依赖，移除 `IAppSettingsStorageService` 与 `AppSettingsStorageService`
- 升级 Avalonia 至 12.1.3、升级 FluentAvalonia 至 3.1.0（解决标题栏标题显示与设置页按钮失效）
- 清理冗余依赖引用，统一移动端与桌面端的包版本声明
