# 方圆作业板（ImmersingHomework）0.2.0.0-beta

发布日期: 2026-09-04

## 📝 概述

这是 ImmersingHomework 在 0.1.0.0-beta 基础上的新版本。本版本围绕作业的“记录、分发与备份”全面增强：新增作业模板、快照与冻结机制、图片 / PDF / 二维码导出、UAF 备份与恢复迁移，推出配套移动端扫码应用，并完善了 ClassIsland 联动与桌面端体验。同时统一了产品名称与视觉形象——方圆作业板（ImmersingHomework）。

## ✨ 新功能

### 作业记录与展示
- 作业模板 - 预设带参数的作业模板，新建作业时一键填充内容并实时预览
- 作业快照与还原 - 每次作业内容变更自动存档快照；还原时支持预览，并可“替换”或“合并”当前作业
- 作业冻结 - 一键冻结当日作业，冻结后无法误改，解除后继续编辑
- 课间布置作业提醒 - 联动 ClassIsland 时，课间弹出提醒，并自动带出“上一节课”科目
- 课后与次日展示 - 支持放学后、第二天第一节课开始前自动展示作业（可配置等待时间）
- 性能优化 - 优化主界面作业面板的加载耗时

### 分享与分发
- 导出为图片 / PDF - 将当日作业排版导出为 PNG 图片或 PDF 文件
- 二维码导出 - 将作业数据以 CBOR 紧凑编码为二维码，扫码即可在其它设备获取；修复二维码未携带标签颜色的异常
- 导出对话框 - 重新设计导出方式选择与结果展示（打开 / 复制等）

### 存储与备份（UAF）
- 引入 UAF（作业通用交换格式）核心库：作业数据以 CSV 载荷内嵌于 PDF，文件自包含、可迁移
- UAF 备份与解包 - 一键将作业打包为 UAF PDF 备份，也可从 UAF PDF 解包还原作业
- 备份设置页 - 支持导出备份、导入恢复与数据迁移
- 存储设置页 - 作业 / 日志 / 输出 / 快照等数据支持查看目录、统计占用空间与清理

### ClassIsland 联动
- 科目接管 - 开启后科目列表由 ClassIsland 同步接管
- 时段识别 - 获取“上一节课”科目、判断课间与课前时段，用于布置作业提醒与定时展示

### 移动端（新）
- Android / iOS 配套应用：扫描桌面端导出的作业二维码，查看当日作业并导出为图片 / PDF，支持保存到设备与系统分享
- 移动端沿用“方圆作业板”名称、图标与视觉风格

### 桌面体验
- 开机自启动
- 浮窗拖动位置记忆
- 全局异常捕获窗口 - 程序异常时友好提示，支持重启与前往反馈
- 多实例检测 - 重复启动时给出明确提示而非静默失败
- 新图标与新 Banner，产品名称统一为“方圆作业板”

## 🔧 修复

- 修复复制作业图片在 Linux 上的异常行为
- 修复二维码传输未携带标签颜色的异常
- 修复 UAF PDF 生成相关问题

## 📦 分发说明

- 桌面端：手动分发安装包（Windows / macOS / Linux）
- 移动端：Android 分发 APK
- Launcher 与自动更新基础设施已就位，但本版本暂未启用自动更新，请留意后续版本
