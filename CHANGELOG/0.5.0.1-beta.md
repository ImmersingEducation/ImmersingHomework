# 方圆作业板（ImmersingHomework）0.5.0.1-beta

发布日期: 2026-11-15

## 📝 概述

这是 ImmersingHomework 在 0.5.0.0-beta 基础上的新版本，集中修复 `immersinghomework://homework?date=` 纯查询路由取错日期的问题。查询参数中的日期现在会先经过规整再解析，带前缀、重复参数、单数字月日或带时间部分的写法都能取到正确的那一天；查询失败时也不再静默回退到当天，便于脚本与外部程序可靠地调用。

## 🔧 修复

- 修复 `homework` 路由的 `date` 参数解析错误 - 参数值中带有多余的 `date=`、整段 `immersinghomework://homework?date=...`、全角横线、单数字月日（`2026-1-5`）或 ISO 时间部分（`2026-11-15T10:20:30`）时，此前会解析失败并静默返回当天数据；现在会先规整为 `yyyy-MM-dd` 再解析
- 日期兼容 - 斜杠分隔（`2026/11/15`）与常见的破折号写法一并支持；仍无法识别时按当天处理，与缺省行为保持一致
