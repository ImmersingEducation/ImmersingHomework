# 方圆作业板（ImmersingHomework）0.4.0.1-beta

发布日期: 2026-10-18

## 📝 概述

这是 ImmersingHomework 在 0.4.0.0-beta 基础上的新版本。本版本的主题是「导出观感与主界面一致」与「ClassIsland 联动更可控」：作业图片导出从 ImageSharp 手绘排版全面切换为 Avalonia 组件树离线渲染，导出的图片与界面上看到的作业卡片同源同观感；ClassIsland 联动新增「课后提醒布置作业」独立开关，并在切换联动开关时提供一键重启生效弹窗。关于页翻新出「鸣谢」分组与寄语，横幅换上新图，各设置页在宽屏下的排版也统一收窄。

## ✨ 新功能

### 作业导出
- 作业回执组件 - `ImmersingHomework.Shared` 新增 `HomeworkReceiptService`，用 Avalonia 控件树（标题、科目分组、作业条目、标签、落款）描述一张作业图的内容，可被导出链路复用
- Avalonia 离线渲染 - 作业图片导出改为对回执控件树做 `Measure` / `Arrange` 后用 `RenderTargetBitmap` 渲染为 PNG，图片与主界面作业卡片观感一致
- 导出接口整理 - `HomeworkToImage` 更名为 `SaveHomeworkImage`，保存目录自动创建

### ClassIsland 联动
- 课后提醒布置作业开关 - 联动设置页新增独立开关，可单独控制课间是否弹出作业布置提醒，不再与其它联动行为耦合
- 重启生效弹窗 - 切换 ClassIsland 联动开关时弹出「该设置需要重启生效」对话框，可直接一键重启软件

### 界面
- 关于页翻新 - 关于页新增「鸣谢」分组（开发平台与 UI 框架、UAF / PDF 技术支持、HarmonyOS Sans 字体、ClassIsland 与 SecRandom 参考致谢、同学反馈致谢），并在底部加入寄语文案
- 新横幅 - 关于页横幅换新图，图片资产统一到 `ImmersingHomework.Shared/Assets/banner-mini.png`，移除主工程重复的横幅资源
- 设置页排版收窄 - 各设置页内容统一限制 `MaxWidth`，宽屏下不再被拉伸到全宽

## 🔧 修复

- 修复教学安全模式下拉框初始未选中当前策略
- 修复编辑作业时已有标签未被回填为选中状态（标签控件重建后恢复选中）
- 修复作业条目长文本不换行
- 修复作业布置提醒窗口因跨线程操作导致的显示异常（「变成滚木」），IPC 回调统一切回 UI 线程
- 修复作业布置提醒弹窗打开主界面后未关闭自身
- 修复上一节课为滚木时仍弹出作业布置提醒

## ♻️ 重构与依赖

- 作业图片服务瘦身 - `HomeworkImageService` 移除约 380 行手绘排版与字体测量代码（元素计算、标签宽度计算、逐元素绘制等），只保留布局驱动与 PNG 落盘，渲染细节收敛到 Shared 的回执组件
- ClassIsland 联动方法提取 - 抽取课间 / 放学 / 课前提醒的相关逻辑，主界面显示与隐藏统一走 UI 线程调度
- 精简发布产物 - 发布流水线打包类型收敛：Windows 保留 Portable 与安装包，Linux 保留 Portable 与 Deb，macOS 仅 Portable，移除单文件与部分安装包变体
