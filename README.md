# 方圆作业板（ImmersingHomework）- 班级大屏作业板

一个现代化的**班级大屏作业板**应用，使用 Avalonia UI 框架开发。面向教室场景：老师把作业按科目记录到大屏上供全班查看，并可将作业以**图片 / PDF / 二维码**的形式分发给学生。

最新版本：0.5.0.0-beta

## 功能特性

- 📚 **科目管理** - 自定义添加和管理科目（可交由 ClassIsland 同步接管）
- ✏️ **作业记录** - 按科目记录和展示作业，支持日期切换与日历选择
- 🏷️ **标签系统** - 使用标签分类和筛选作业
- 🧩 **作业模板** - 预设带参数的模板，新建作业一键填充并实时预览
- 📸 **快照与冻结** - 内容变更自动存档快照；一键冻结防误改，长按解冻，误操作后可替换或合并还原
- 🕰️ **时光机** - 底部时间轴横向排列当天快照，左右滑动或方向键即可穿越查看任意时刻的作业
- 🖱️ **拖拽整理** - 作业条目可在科目分组与瀑布流列之间自由拖动排序，位置自动记忆
- 🎞️ **动效主界面** - 顶栏、作业编辑抽屉与科目轮盘、作业增删改与快照切换动画、自动上下往复滚动
- 🎨 **外观定制** - 主界面列数、标题文字、背景图片（透明度 / 模糊度）、高级材质（Windows）与主题色
- 📤 **多种导出** - 导出为图片（PNG）、PDF，或通过二维码发送到其它设备
- 💾 **UAF 备份** - 作业以自包含 PDF（内嵌数据）打包备份，支持解包恢复与数据迁移
- 📱 **移动端配套** - Android / iOS 扫码应用，扫码即取作业
- 🔄 **ClassIsland 联动** - 科目同步、课间提醒布置作业（可按科目与连堂单独设置）、课后与次日课前自动展示作业
- 📜 **一言展示** - 主界面可展示随机一言
- 🖥️ **全屏展示** - 适合班级大屏使用
- 🎯 **浮窗按钮** - 主窗口隐藏时显示可拖动浮窗，可吸附屏幕左右两侧，纵向位置自动记忆
- 🔔 **托盘图标与开机自启**
- 🛡️ **健壮性** - 单实例检测、全局异常捕获、Serilog 日志

## 平台支持

- **桌面端**: ✅ Windows ✅ macOS ✅ Linux（X11 / Wayland）
- **移动端**: Android（APK 分发）

## 技术栈

- **框架**: .NET 10.0
- **UI**: Avalonia 12.1 + FluentAvalonia 3.1，默认字体 HarmonyOS Sans SC，主界面可选高级材质（CompositionMaterial）
- **导出**: SixLabors.ImageSharp（图片）、iText7（PDF）、ZXing.Net（二维码）
- **联动**: ClassIsland.Shared / ClassIsland.Shared.IPC
- **日志**: Serilog

## 主要功能页面

- **欢迎向导** - 首次启动时的初始化配置
- **主窗口** - 顶栏与作业瀑布流展示、日历切换、自动滚动、拖拽整理、作业编辑抽屉、冻结 / 时光机还原、分享导出
- **设置窗口** - 基础、主界面、科目、标签、作业模板、联动、存储、备份、更新、关于
- **移动端** - 扫码解析 → 查看作业 → 导出图片 / PDF

## 数据与日志

应用运行目录下：

- `Data/Homeworks/` - 每日作业与自动快照数据（JSON）
- `Outputs/` - 导出的图片 / PDF 文件
- `Logs/` - Serilog 滚动日志
- 备份与迁移请在设置页 → 备份设置中操作
